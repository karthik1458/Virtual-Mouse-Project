# Virtual Mouse Project

This is a simple virtual mouse project made using Python.

In this project, I used hand tracking to control the mouse pointer with fingers.  
The mouse moves with finger movement, and clicking works when two fingers come close.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## What I Learned
- Hand tracking
- Gesture control
- Basic computer vision

# 🖐️ Virtual Mouse using Hand Tracking

This project is a simple virtual mouse built using Python.
It allows users to control the mouse cursor using hand gestures through a webcam.

---

## 🚀 Features

* Move cursor using index finger
* Click using thumb and index finger
* Real-time hand tracking
* No physical mouse required

---

## 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* PyAutoGUI

---

## 📚 What I Learned

* Hand tracking using MediaPipe
* Gesture recognition
* Mapping camera coordinates to screen
* Real-time computer vision

## ▶️ How to Run

1. Install libraries:

```bash
pip install opencv-python mediapipe pyautogui
```

2. Run the program:

```bash
python virtual_mouse.py
```

---

## 📸 Output

This project controls the mouse using hand gestures.

* Cursor moves with index finger
* Click happens when thumb and index finger come close
